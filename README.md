# My Attendance

A personal student attendance tracker built with Flask, HTML, CSS, JavaScript and SQLite.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal.
3. Create a virtual environment (recommended):

   `python -m venv venv`

4. Activate it on Windows:

   `venv\Scripts\activate`

5. Install Flask:

   `pip install -r requirements.txt`

6. Start the app:

   `python app.py`

7. Open the address shown in the terminal, normally:

   `http://127.0.0.1:5000`

Your attendance data is stored locally in `attendance.db`.
